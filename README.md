# 动态流式二维码 2.7.2

电脑轮播二维码，手机摄像头接收文本或文件。传输内容不上传服务器。

- [接收端](https://gura8390.github.io/TEST.GITHUB.IO/)：打开后请求摄像头权限，允许后自动扫描，默认使用后置摄像头。
- [发送端](https://gura8390.github.io/TEST.GITHUB.IO/send/)：输入文本或选择文件，点击“开始发送”，将屏幕对准接收端摄像头。

接收端保留在仓库根目录，发送端位于 `send/`。两端的脚本、样式、Worker、图标和第三方许可均完整包含，可各自独立部署。手机摄像头需要 HTTPS 或 localhost；接收端缓存就绪后可离线使用。

如果仍显示旧版本，请联网刷新并确认页头为 2.7.2。刷新会清空正在接收的进度，请在接收前更新。

原始内容最多 16 MiB，同时受压缩后二维码容量限制；随机或已压缩文件通常只能传几百 KiB。支持缺帧补发、分组 XOR 恢复，以及最终 SHA-256、长度和 UTF-8 校验。实际传输速度取决于手机、屏幕、距离及反光。自动化验证不能替代真实手机验收。

第三方依赖 qrcode-generator、pako 和 jsQR 的许可分别保存在 `send/licenses/` 和 `licenses/` 中。
